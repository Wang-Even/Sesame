## 随机化内容

每个并行环境在回合开始时独立采样，在该回合内保持参数固定。

| 项目 | 范围与处理 |
| --- | --- |
| 有效接触摩擦系数 | 0.6–1.2，64 个离散档位 |
| 各刚体质量与惯量 | 同一个整机倍率 0.8–1.2；总质量约 0.3072–0.4608 kg |
| 位置驱动刚度 | 基准 5 的 0.8–1.2 倍 |
| 位置驱动阻尼 | 基准 0.0025 的 0.8–1.2 倍 |
| 力矩上限 | 基准 0.18 N·m 的 0.8–1.0 倍 |
| 关节及目标角速度上限 | 基准 10.472 rad/s 的 0.8–1.0 倍 |
| 目标角一阶响应时间常数 | 20–60 ms |
| 指令延迟 | 0、1 或 2 个控制步，即 0–40 ms |
| 初始关节偏移 | ±0.035 rad，随后按关节限位裁剪 |
| 初始偏航角 | ±5° |
| 初始水平速度 | vx、vy 各 ±0.02 m/s |

摩擦随机化通过机器人接触面的材料实现：地面材料保持 0.9，机器人材料在 0.3–1.5 之间取值，双方使用 `average` 合并模式，因此有效接触摩擦为 `(机器人系数 + 0.9) / 2`。代码检查材料绑定和合并模式，并读回 PhysX 中的实际系数。没有改变地面几何或新增坡面。

质量与惯量使用相同倍率，避免质量变化后惯量仍停留在原值。舵机参数同时更新 PhysX 和隐式执行器缓存，确保动作执行与力矩奖励使用一致参数。力矩、速度均不超过源模型上限。延迟历史在每次重置时填充为当前初始目标角，避免带入上一回合指令。

默认关闭观测噪声。域参数由独立 CUDA 随机数生成器采样，以减少对 PPO 随机动作及策略初始化随机序列的干扰。物理和模型计算都在 GPU 上执行；部分 PhysX 属性接口要求的 CPU 张量仅用于属性传输。

## 代码与验证

- `sesame_rl/dr_environment.py`：继承原环境的随机化实现，原 `environment.py` 保持不变。
- `scripts/probe_domain_randomization.py`：GPU 参数读回、同种子重现、不同种子变化、恢复标准参数及短时控制检查。
- `scripts/train_ppo_dr.py`：从头训练、完整参数与源码快照、策略重载和配对评测。
- `scripts/record_ppo_dr_video.py`：指定标准或随机物理条件下的完整策略录像。

`set_domain_randomization(False)` 在下一次重置时恢复原始质量、惯量、摩擦、增益和限幅，并恢复无额外滞后/延迟的原控制器及原初始姿态分布。该模式用于固定参数评测。

实际 GPU 探测已通过，报告见 [domain_randomization_probe.json](../reports/domain_randomization_probe.json)：

- 采样参数与 PhysX 实际读回值、执行器缓存一致，质量最大绝对误差约 `1.49e-8 kg`。
- 相同种子重现相同初态与物理域，不同种子改变物理域；随机模式→标准模式→随机模式可恢复同种子结果。
- 仅重置第 1、7 个环境时，其余环境的物理域、根状态与指令延迟历史不变。
- 16 个环境分别完成随机和标准条件下的 4 秒零动作检查，无跌倒；32 步随机动作检查状态有限。
- 独立小规模训练完成一次 PPO 更新和六组配对评测，策略保存/重载的动作误差为 0。该 smoke 结果仅验证流程，不作为训练效果。

## 训练与评测设计

默认训练种子 42，256 个并行环境，每次收集 32 步，更新 250 次，共 2,048,000 条训练转移。PPO 配置与原基线 JSON 逐项核对，保留原奖励，因此原先缺少累计航向约束的问题可能仍然存在。

训练结束后重新加载检查点，使用留出的种子 2042，在两种条件下各运行 64 个完整回合：

1. 标准参数：原始固定参数与控制器。
2. 随机参数：上述训练随机化分布的新样本。

每种条件分别运行零残差站姿控制、原固定参数 PPO、新 DR PPO。三种控制器必须匹配相同初始状态和实际域参数；评测读取每个选定环境的首个完整回合，统计前向位移、速度、跌倒、时长、偏航、侧移和动作裁剪。随机参数评测是分布内泛化评测，不代表未见范围或真实机器人验证。

```bash
cd /home/ywwang/sesame
CONDA_NO_PLUGINS=true PYTHONDONTWRITEBYTECODE=1 \
  /home/ubuntu/miniforge3/bin/conda run -n env_isaaclab --no-capture-output \
```
