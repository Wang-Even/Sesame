# 绘图说明

仿照用户提供论文图的衬线字体、蓝橙配色、细坐标轴、无背景网格、左上角分面标题；额外提供大左图与右侧上下两图的 overview_paper_layout。图中的英文使用直观指标名称，中文解释保留在报告图注。

训练曲线统一按真实交互步数作因果 EMA：半衰期 131072 步，alpha = 1 - 2^(-步数差 / 131072)。每种方法以一条连续实线连接平滑后的记录值，不显示点标记、虚线和原始辅助线。该平滑参数对所有算法一致，不因记录密度而改变训练跨度。原始值保留于附带 CSV，不新增采样、不外推、不调整 EMA 端点。

每组以首次记录到有效参数更新的日志时间为截取边界，仅显示边界及之后的观测，时间横坐标为原累计训练时间减去该边界时间。该边界受日志频率限制，不等同于精确首次优化器步骤结束时刻。所有方法采用同一规则，不能将扣除的全部时段解释为纯编译时间。评估用时不计入横轴；EMA先用完整历史计算，再裁剪显示，不补造零时刻回报。

周期评估间隔为 32,768 个真实交互步。各组均在首次训练更新后立即进行实测评估，作为零时刻。

基线先分别平滑三个训练种子，再在共同保留步数上计算均值。基线训练曲线仅按绝对真实交互步数展示，不作训练时间横轴对比，曲线均按每种方法一条均值实线展示，不绘制误差带。单种子实验不绘制跨种子误差带。原日志回报窗口为 PPO 最近100回合、DQN/SAC最近256回合。

所有保留时间间隔均以实线连接已有记录；连线用于呈现趋势，间隔内不增加评估数据。Return 保持原始量纲，时间单位为分钟。最终测试图按评估类别连接原始均值，基线测试保留样本标准差阴影；类别间连线仅辅助比较。最终测试数据、表格和正文比较数值均不平滑；计算成本及相近总时间对照表仍使用含启动开销的原始计时。

重画：在 Sesame 根目录运行 `python3 scripts/plot_course_report_paper_style.py --source reports/course_rerun_20261116 --suite runs/course_comparison_dense_20261116 --extended-ppo runs/course_ppo_extended_dense_20261116`。`display_curve_data.csv` 保留所有原始值、EMA值、实际步数、原始时间和seed，并增加startup_s、plot_training_s及included列。`smoothing_protocol.json` 保存各组边界与规则，`plot_manifest.json` 保存输入和图片哈希。PDF/SVG为独立矢量图，PNG为320dpi报告插图。绘图阶段仅处理已完成的训练记录。

参考与控制器执行轨迹采用同一段 6 秒、50 Hz 原始记录，连续实线直接连接各帧，不作 EMA 平滑、时间重对齐或端点修正。CSV 保存全部 301 帧，JSON 保存来源与校验值。这是参考采集阶段的控制器仿真检验，不是训练后策略推理。
